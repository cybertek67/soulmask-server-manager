# Security

## Never publish live world folders

Soulmask launchers may contain plain-text admin or server passwords. Save databases also contain player, tribe, and world information. Keep `World-XX`, `ManagerBackups`, SteamCMD logs, and locally generated settings outside the repository.

## Reporting a security problem

If this project is published publicly, add a private contact method here before accepting reports.

Do not post passwords, API keys, save databases, account identifiers, or private server addresses in a public issue.
